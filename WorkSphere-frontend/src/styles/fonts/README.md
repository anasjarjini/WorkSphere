# Local fonts

These variable fonts are served with the application. Builds and browsers do not need Google Fonts access.

- DM Sans, Lexend, Roboto Mono: https://github.com/google/fonts/tree/main/ofl (respective dmsans, lexend, robotomono directories).
- Material Symbols Outlined: https://github.com/google/material-design-icons/tree/master/variablefont

Downloaded September 5, 2026. License files are included alongside the fonts.
Keep fonts.css and these assets together; Angular bundles the referenced fonts into the build.
