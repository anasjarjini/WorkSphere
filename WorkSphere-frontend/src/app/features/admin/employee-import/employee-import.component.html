Importer des employés

Importez vos employés en masse via un fichier CSV. Téléchargez d'abord le modèle pour respecter le format attendu, puis glissez-déposez votre fichier ci-dessous.

Modèle CSV

Colonnes attendues : first_name, last_name, email, role, job_title, department, hire_date, salary

Le fichier doit être encodé en UTF-8. Le rôle doit être manager ou employe. La date doit être au format DD/MM/YYYY.
